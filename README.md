# پنل مدیریت فروشگاه موبایل

پنل مدیریت کامل (فارسی و راست‌به‌چپ) برای فروشگاه موبایل و لوازم جانبی — با تم آبی-سفید، داشبورد تحلیلی فروش، مدیریت محصولات و دسته‌بندی‌ها، ثبت فروش، یادداشت‌ها، ماشین‌حساب و یادآور روزانهٔ قیمت.

## راه‌اندازی

```bash
# نصب وابستگی‌ها (در صورتی که لازم باشد)
bun install

# ساخت/به‌روزرسانی دیتابیس از روی اسکیما
bun run db:push

# درج دادهٔ اولیه (کاربران، دسته‌ها، ۱۲ محصول با تصویر، ۸۹ فروش نمونه)
bun scripts/seed.ts

# اجرای محلی
bun run dev        # http://localhost:3000
```

> دیتابیس SQLite در `db/custom.db` ذخیره می‌شود (متغیر `DATABASE_URL` در `.env`).

## حساب‌های پیش‌فرض (پس از Seed)

| کاربر | رمز | نقش |
|---|---|---|
| `taha` | `taha2212` | مدیر کل (Super Admin) |
| `sara` | `sara1234` | کارمند فروش (Staff) |

ثبت‌نام عمومی وجود ندارد؛ حساب‌های جدید فقط مدیر کل از بخش «کاربران» می‌سازد.

## ماژول‌ها

1. **احراز هویت** — ورود با نام کاربری/رمز، کوکی HttpOnly امضاشده، هش scrypt، قفل حساب بعد از ۵ تلاش ناموفق (۱۵ دقیقه)، لاگ کامل ورودها (IP، دستگاه، موفق/ناموفق)
2. **نقش‌ها و دسترسی (RBAC)** — چهار نقش با ماتریس دسترسی؛ بررسی دسترسی همیشه سمت سرور انجام می‌شود
3. **داشبورد** — KPI فروش امروز/۷روز/۳۰روز/بازه دلخواه، روند روزانه با مقایسهٔ بازهٔ قبل، سهم دسته‌ها (دونات)، پرفروش‌ها، آخرین فروش‌ها، هشدارها (کم‌موجودی، بدون عکس، بدون قیمت، قیمت بررسی‌نشده)
4. **محصولات** — فیلدهای کامل (SKU، برند، قیمت خرید/فروش/تخفیف، آستانه هشدار، ویژگی‌های کلید-مقدار مثل رنگ/حافظه/IMEI)، چند تصویر (آپلود + URL)، سئو، جستجو/فیلتر/مرتب‌سازی/صفحه‌بندی، ویرایش سریع قیمت و موجودی در جدول، کپی، سطل زباله و بازگردانی، عملیات گروهی (وضعیت/دسته/درصد قیمت)، ورود و خروج CSV
5. **ثبت فروش** — قیمت لحظهٔ فروش ذخیره می‌شود، موجودی خودکار کم و در صفر شدن وضعیت «ناموجود» می‌شود؛ لغو فروش با دلیل الزامی و برگشت موجودی؛ تغییر دستی موجودی با ثبت دلیل؛ تاریخچه با فیلتر بازه و خروجی اکسل (CSV)
6. **دسته‌بندی‌ها** — ساختار درختی (دستهٔ اصلی + زیرمجموعه)، آیکن، تعداد محصول؛ دستهٔ دارای محصول قابل حذف نیست
7. **یادداشت‌ها** — سنجاق، ۶ رنگ، جستجو، اتصال به محصول
8. **ماشین‌حساب شناور** — استاندارد (کیبورد + تاریخچه) و فروشگاهی (قیمت بعد از تخفیف، سود و حاشیه سود)
9. **یادآور روزانهٔ قیمت** — ساعت قابل تنظیم (به وقت ایران)؛ پنجرهٔ «قیمت‌ها تغییر کرده؟» با «تغییری نکرده» یا جدول ویرایش سریع قیمت‌ها با ذخیرهٔ یکجا؛ در صورت بی‌پاسخی هر ۳۰ دقیقه تکرار و هشدار در داشبورد می‌ماند؛ تاریخچهٔ قیمت هر محصول ثبت می‌شود
10. **کاربران و لاگ‌ها** — ساخت کاربر، تغییر نقش/وضعیت/رمز، لاگ ورود و لاگ تغییرات (Audit Log)
11. **تنظیمات** — نام فروشگاه، واحد پول (تومان/ریال)، یادآور قیمت، وب‌هوک محصولات، کلید API با امکان تولید مجدد، کلید هوش مصنوعی Gemini (ذخیره روی سرور، نمایش ماسک‌شده)
12. **API عمومی** — `GET /api/v1/products` و `GET /api/v1/categories` با هدر `x-api-key` (کلید در تنظیمات) برای اتصال ربات‌ها و سرویس‌های بیرونی؛ وب‌هوک رویدادهای ساخت/ویرایش/حذف محصول
13. **هوش مصنوعی Gemini** — دکمه «تولید با هوش مصنوعی» در فرم محصول برای ساخت توضیح فارسی بر اساس نام/برند/مشخصات؛ دستیار گفت‌وگوی شناور در تمام پنل که به داده‌های زنده فروشگاه (موجودی کم، ناموجود، پرفروش‌ها، آخرین فروش‌ها) متصل است؛ کلید از تنظیمات یا متغیر محیطی `GEMINI_API_KEY`
14. **خروجی اکسل بومی** — فایل `xlsx` واقعی با ستون‌های فارسی، راست‌به‌چپ، هدر رنگی و فیلتر خودکار برای محصولات و فروش‌ها (`/api/export/excel`) در کنار خروجی CSV

## متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `DATABASE_URL` | `file:/home/z/my-project/db/custom.db` | مسیر فایل SQLite |
| `AUTH_SECRET` | مقدار توسعهٔ محلی | کلید امضای توکن نشست — در محیط واقعی حتماً تنظیم شود |
| `GEMINI_API_KEY` | — | کلید Gemini به‌عنوان جایگزین/پشتیبان کلید ذخیره‌شده در تنظیمات |

نمونهٔ `.env.example`:

```env
DATABASE_URL=file:./db/custom.db
AUTH_SECRET=change-me-to-a-long-random-string
```

## تست دستی سریع

1. ورود با `taha / taha2212`
2. در «محصولات» روی «ثبت فروش» یک گوشی → موجودی کم می‌شود و در «تاریخچه فروش» ثبت می‌شود
3. «لغو فروش» با دلیل → موجودی برمی‌گردد
4. ماشین‌حساب با `Ctrl+K` (جستجو) و آیکن ماشین‌حساب در هدر
5. «یادآور قیمت امروز» در هدر → «بله» → جدول ویرایش سریع قیمت
6. ورود با `sara / sara1234` → منوی «کاربران» دیده نمی‌شود و API هم درخواست مدیریتی را با 403 رد می‌کند

## یادداشت‌های پیاده‌سازی

- **یادآور قیمت**: زمان‌بندی در مرورگر انجام می‌شود (polling هر دقیقه به وقت ایران). نسخهٔ سرورمحور (node-cron/BullMQ) برای استقرار واقعی قابل افزودن است.
- **حذف نهایی محصول**: محصولاتی که سابقهٔ فروش دارند حذف فیزیکی نمی‌شوند (یکپارچگی گزارش‌ها)؛ از آرشیو استفاده کنید.
- تصاویر محصولات نمونه با هوش مصنوعی تولید شده‌اند و شبیه برندهای واقعی هستند اما رسمی نیستند.
